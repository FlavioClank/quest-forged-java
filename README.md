# Quest Forged Java

Crie uma página web em React e Tailwind CSS chamada "JavaQuest" com tema escuro (Dark Mode) voltada para aprendizado de Java Puro. 

A tela deve ter:

1. Um Header estilo Duolingo mostrando Nível (Nível 1: Padawan Java), barra de XP e moedas.

2. Uma barra lateral (sidebar) com a trilha de módulos: Fundamentos, Orientação a Objetos, Collections e Projetos Reais (Calculadora, Login e CRUD JDBC).

3. Uma área central dividida em duas colunas: esquerda com a explicação didática do conceito em Java Puro, e direita com uma caixa de código (simulando uma IDE) mostrando o código Java com botão de copiar e botão "Simular Execução" que mostra o output no console abaixo.

Faça tudo em um único arquivo funcional usando componentes limpos e Tailwind, salvando o progresso no localStorage.
